# Журнал архитектурных решений (Architecture Decision Records)

## ADR-001: Стратегия хранилища и динамическое разрешение путей
- **Контекст:** Требовалось локальное, надежное хранилище для реляционных моделей (проекты, версии, главы, 193+ сцены, кандидаты, метрики) с поддержкой ACID и воспроизводимости.
- **Решение:** Использован SQLite по умолчанию через SQLAlchemy 2.0 с автоматической готовностью перехода на PostgreSQL (`DATABASE_URL`). Для предотвращения проблем с относительными путями при запуске Uvicorn/CLI из подкаталогов настроено динамическое абсолютное разрешение `project_root / "data" / "story_forecaster.db"`.
- **Статус:** Принято и проверено.

## ADR-002: Строгая изоляция будущего через `discourse_seq <= cutoff`
- **Контекст:** Риск утечки будущего (future leakage) при ретроспективном прогнозировании искажает результаты валидации и бэктестов.
- **Решение:** Внедрен неизменяемый контракт `ForecastScope`. Каждая сцена индексируется уникальным возрастающим `discourse_seq`. Все поисковые, редукторные и извлекающие запросы фильтруются на уровне базы данных (`Scene.discourse_seq <= scope.target_max_discourse_seq`).
- **Статус:** Принято и верифицировано тестом `test_retrieval_scope_boundary_zero_leakage`.

## ADR-003: Реверс-инжиниринг и алгоритм дешифровки Author.Today
- **Контекст:** Главы произведения «Система Абсолютного З.Л.А.» отдаются защищенным API Author.Today в зашифрованном виде.
- **Решение:** Путем анализа JavaScript бандла читалки восстановлен алгоритм дешифрования:
  - Заголовок ответа `Reader-Secret`.
  - Ключ XOR: `secret[::-1] + "@_@"`.
  - Операция: `chr(ord(c) ^ ord(key[i % len(key)]))`.
  - Все 24 главы выгружены и сохранены локально в `data/target/chapters/` в чистом UTF-8.
- **Статус:** Принято.

## ADR-004: Гибридный поиск BM25 + Dense + RRF (k=60)
- **Контекст:** Ограниченный контекст прогноза требует выборки наиболее релевантных свидетельств без переполнения токен-бюджета.
- **Решение:** Реализован точный алгоритм BM25 с гиперпараметрами `k1 = 1.2`, `b = 0.75` и сглаженным IDF Робертсона-Спэрка Джонса. Результаты лексического поиска объединяются с плотными рангами через Reciprocal Rank Fusion ($RRF = \sum \frac{1}{60 + \text{rank}}$).
- **Статус:** Принято.

## ADR-005: 5-статусный реестр канона H.O.T.D.
- **Контекст:** Фанфик сочетает оригинальный мир аниме «Школа мертвецов» с кроссовером (Кадзума, Хорадримский Куб). Прямой перенос событий оригинала вызывал бы ложные прогнозы немедленного зомби-апокалипсиса.
- **Решение:** Разделение на 4 ортогональные оси (`relation`, `evidence`, `dependency`, `occurrence`). Установлено временное смещение (мирный период Фудзими, поступление за 1 год до Прорыва Данжа). Все зависимые события помечены как `DEPENDS_ON_CHANGED_CONDITIONS`.
- **Статус:** Принято.

## ADR-006: Двухшаговый генератор луча гипотез (Beam Search)
- **Контекст:** Генерация полного текста главы «в один проход» ведет к однотипным продолжениям и галлюцинациям.
- **Решение:** Разделение процесса на два уровня абстракции:
  1. *Шаг 1 (Макро-топология):* Генерация 3 различных структур главы (POV, нарративный режим, темп, фокус сюжетной линии).
  2. *Шаг 2 (Микро-события):* Синтез 3–6 проверяемых сюжетных битов для каждой топологии с мотивировками, конфликтом и клиффхэнгером.
- **Статус:** Принято.

## ADR-007: Zero-Dependency парсеры EPUB и FB2
- **Контекст:** Необходимость парсинга 13 книг мета-корпуса (FB2) и внешних электронных книг (EPUB) без раздувания зависимостей тяжелыми библиотеками.
- **Решение:** Реализованы модули `fb2_parser.py` и `epub_parser.py` исключительно на стандартной библиотеке Python (`xml.etree.ElementTree`, `zipfile`, `html.parser`).
- **Статус:** Принято.
