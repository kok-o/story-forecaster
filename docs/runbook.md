# Руководство по эксплуатации (Operations Runbook)

Руководство описывает типовые рабочие процессы запуска, диагностики, прогнозирования и обновления системы Story Forecaster.

---

## 1. Системные требования и окружение

- **Python**: 3.10+ (рекомендуется 3.12 / 3.13)
- **Операционная система**: Windows / Linux / macOS
- **Зависимости**:
  ```bash
  pip install -r backend/requirements.txt
  # либо
  pip install fastapi uvicorn typer rich sqlalchemy pydantic pytest httpx jinja2
  ```

---

## 2. Первичная диагностика системы (Doctor)

Перед запуском конвейеров выполните проверку готовности среды:

```bash
# Диагностика локальной среды, БД и корпуса
python -m story_forecaster.cli doctor

# Диагностика с проверкой API-ключа Gemini (при наличии)
python -m story_forecaster.cli doctor --probe-api
```

Команда валидирует:
1. Версию Python и платформу.
2. Подключение к SQLite базе данных и целостность таблиц.
3. Доступность файлов целевых глав и `manifest.json`.
4. Наличие каталогов 13 книг мета-корпуса FB2 (~20 млн знаков).
5. Наличие статических ресурсов веб-интерфейса (`frontend/`).
6. Готовность провайдера моделей.

---

## 3. Сквозные сценарии работы (Workflows)

### 3.1. Индексация и первичное наполнение (Ingest)
Если база данных создается с нуля:
```bash
python -m story_forecaster.cli ingest --manifest data/target/chapters/manifest.json
```

### 3.2. Просмотр структуры и оглавления (Inspect)
```bash
python -m story_forecaster.cli inspect
```
Выводит сводную таблицу по всем главам с количеством символов, разбиением на сцены и диапазонами `discourse_seq`.

### 3.3. Генерация прогноза следующей главы (Forecast)
```bash
# Прогноз продолжения после Главы 24 (на Главу 25)
python -m story_forecaster.cli forecast --cutoff-chapter 24

# Прогноз после Главы 23 (на Главу 24)
python -m story_forecaster.cli forecast --cutoff-chapter 23
```
Система формирует луч из 3 структурных вариантов (POV, темп, режим) и 3–6 проверяемых сюжетных битов для каждого.

### 3.4. Слепой бэктест на скрытой главе (Backtest)
```bash
# Проверка качества: прогноз Главы 24 по главам 1–23 со скрытием эталона
python -m story_forecaster.cli backtest --cutoff-chapter 23
```
Выводит:
- Топологическое соответствие (Topology Score).
- Event Precision, Event Recall, Event F1 (алгоритм 1-to-1 matching).
- Метрики Best@1 и Oracle@K.
- Детальную таблицу сопоставления каждого бита с реальными событиями.

### 3.5. Абляционный бенчмарк архитектуры (Ablation)
```bash
python -m story_forecaster.cli ablation
```
Сравнивает 4 конфигурации:
- **B0 Baseline**: только базовый контекст без памяти и канона (F1 = 0.615).
- **Config A**: базовый контекст + гибридный поиск BM25/RRF (F1 = 0.727).
- **Config B**: поиск + 5-статусный реестр канона HOTD (F1 = 0.800).
- **Config C**: полная система (поиск + канон + память + тропы N.B., F1 = 0.889).

### 3.6. Гибридный поиск по сюжету (Search)
```bash
python -m story_forecaster.cli search "Хорадримский Куб" --cutoff-chapter 24 --top-k 5
python -m story_forecaster.cli search "пыльца фей" --cutoff-chapter 24 --top-k 5
```
Строго соблюдает нулевую утечку будущего (только сцены с `discourse_seq <= cutoff`).

### 3.7. Инкрементальное добавление вышедшей главы (Update)
Когда автор N.B. выпускает новую главу:
```bash
python -m story_forecaster.cli update --file path/to/new_chapter.txt --title "Глава 25"
```
Глава автоматически нормализуется, разбивается на сцены с непрерывным `discourse_seq` и связывается с произведением без переиндексации всей книги.

## 4. Запуск веб-сервера и UI (Web Interface)

```bash
# Запуск REST API и веб-интерфейса на порту 8000
python -m story_forecaster.cli serve --host 127.0.0.1 --port 8000
```
- **Web UI:** [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Interactive Swagger Docs:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

Интерфейс предоставляет 5 интерактивных экранов:
1. **Прогноз (Forecast):** Интерактивная генерация луча гипотез с просмотром битов и клиффхэнгеров.
2. **Слепой бэктест (Backtest):** Оценка качества и 1-to-1 сопоставление с эталоном.
3. **Гибридный поиск (Search):** Поиск по ключевым терминам и артефактам с контролем отсечки.
4. **Реестр канона (Canon):** 4 ортогональные оси канонических элементов HOTD.
5. **Тропы автора (Author Tropes):** Просмотр прецедентов и цитат из 13 книг мета-корпуса.

## 5. Запуск тестового набора (Automated Tests)

```bash
# Запуск всех 27 автоматических тестов
python -m pytest backend/tests -v
```
Все тесты изолированы, не требуют подключения к сети или платных API ключей и проверяют архитектурные инварианты.
