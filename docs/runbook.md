# Руководство по эксплуатации (Operations Runbook)

Руководство описывает типовые рабочие процессы запуска, диагностики, прогнозирования, написания сцен фанфика, планирования арок и управления фоновыми задачами в системе Story Forecaster.

---

## 1. Системные требования и окружение

- **Python**: 3.10+ (рекомендуется 3.11 / 3.12 / 3.13)
- **Операционная система**: Windows / Linux / macOS
- **Зависимости**:
  ```bash
  pip install -e ".[dev]"
  ```

---

## 2. Первичная диагностика системы (Doctor)

Перед запуском конвейеров выполните проверку готовности среды:

```bash
# Диагностика локальной среды, БД и корпуса
python -m story_forecaster.cli doctor

# Диагностика с проверкой API-ключа Gemini (при наличии)
python -m story_forecaster.cli doctor --probe-api
```

Команда валидирует:
1. Версию Python и платформу.
2. Подключение к SQLite базе данных, внешние ключи и целостность таблиц.
3. Доступность файлов целевых глав и `manifest.json`.
4. Наличие каталогов 13 книг мета-корпуса FB2 (~20 млн знаков).
5. Наличие статических ресурсов веб-интерфейса (`frontend/`).
6. Готовность провайдера моделей.

## 3. Сквозные сценарии работы (Workflows)

### 3.1. Индексация и первичное наполнение (Ingest)
Если база данных создается с нуля:
```bash
python -m story_forecaster.cli ingest --manifest data/target/chapters/manifest.json
```

### 3.2. Просмотр структуры и оглавления (Inspect)
```bash
python -m story_forecaster.cli inspect
```
Выводит сводную таблицу по всем главам с количеством символов, разбиением на сцены и диапазонами `discourse_seq`.

### 3.3. Генерация прогноза следующей главы (Forecast)
```bash
# Прогноз продолжения после Главы 24 (на Главу 25)
python -m story_forecaster.cli forecast --cutoff-chapter 24

# Прогноз после Главы 23 (на Главу 24)
python -m story_forecaster.cli forecast --cutoff-chapter 23
```
Система формирует луч из 3 структурных вариантов (POV, темп, режим) и 3–6 проверяемых сюжетных битов для каждого с точными ссылками на источники.

### 3.4. Слепой бэктест на скрытой главе (Backtest)
```bash
# Проверка качества: прогноз Главы 24 по главам 1–23 со скрытием эталона
python -m story_forecaster.cli backtest --cutoff-chapter 23
```
Выводит:
- Топологическое соответствие (Topology Score).
- Event Precision, Event Recall, Event F1 (строгий 1-to-1 matching с пенализацией противоположных исходов).
- Метрики Best@1 и Oracle@K.
- Таблицу сопоставления каждого бита с реальными событиями и выявленные противоречия.

### 3.5. Абляционный бенчмарк архитектуры (Ablation)
```bash
python -m story_forecaster.cli ablation
```
Сравнивает конфигурации:
- **B0 Baseline**: недавний контекст последних сцен без внешней памяти и канона.
- **B1 Memory**: контекст + память на свидетельствах EvidenceReducer.
- **B2 Hybrid**: контекст + память + гибридный поиск BM25 с русской морфологией.
- **Full**: полная система с оверлеями канона и прецедентами автора.

### 3.6. Гибридный поиск по сюжету (Search)
```bash
python -m story_forecaster.cli search "Хорадримский Куб" --cutoff-chapter 24 --top-k 5
python -m story_forecaster.cli search "пыльца фей" --cutoff-chapter 24 --top-k 5
```
Строго соблюдает нулевую утечку будущего (только сцены с `discourse_seq <= cutoff`).

### 3.7. Инкрементальное добавление вышедшей главы (Update)
Когда автор N.B. выпускает новую главу:
```bash
python -m story_forecaster.cli update --file path/to/new_chapter.txt --title "Глава 25"
```
Глава автоматически нормализуется, разбивается на сцены с непрерывным `discourse_seq` и связывается с произведением без разрушения существующих версий.

### 3.8. Режим написания фанфика (Fanfic Writing & Branches)
1. Создание изолированной ветки от точки отсечки:
   `POST /api/writing/branches` с указанием исходного произведения и главы отсечки.
2. Составление структурированного плана сцены (`ScenePlan`): POV, речевой профиль, обязательные биты, цель, ограничения.
3. Генерация черновика через `POST /api/writing/scenes/draft` с цитированием источников.
4. Валидация предложенной дельты состояния (`ProposedStateDelta`) и приёмка сцены: `POST /api/writing/scenes/accept`.
5. Откат нежелательного ранения или модификации: `POST /api/writing/branches/{id}/rollback`.
6. Экспорт готового текста ветки: `GET /api/writing/branches/{id}/export?format=markdown`.

### 3.9. Планирование длинных арок и редакторский контроль (Arcs & Editorial)
1. Создание плана арки: `POST /api/arcs` с этапами (`milestones`) и обещаниями читателю (`promises`).
2. Аудит сюжетных обязательств: `GET /api/arcs/{id}/commitments` выявляет неразвивающиеся линии (>4 сцен) и циклические повторения конфликтов.
3. Редакторский аудит главы: `POST /api/editor/review` вычисляет вариативность темпа, штраф за штампы, соответствие голосов персонажей и причинную связность.

### 3.10. Управление фоновыми задачами (Task Queue)
- Постановка задачи: `POST /api/tasks` с указанием шагов и лимита бюджета (`max_cost_usd`).
- Мониторинг прогресса: `GET /api/tasks/{id}` возвращает процент выполнения и текущий статус.
- Кооперативная отмена: `POST /api/tasks/{id}/cancel`.

## 4. Запуск веб-сервера и UI (Web Interface)

```bash
# Запуск REST API и веб-интерфейса на порту 8000
python -m story_forecaster.cli serve --host 127.0.0.1 --port 8000
```
- **Web Dashboard:** [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Interactive Swagger Docs:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

В интерфейсе доступны вкладки:
1. **Forecast & Benchmark:** прогноз гипотез, слепой бэктест, абляция, поиск и оверлеи канона.
2. **Fanfic Writer:** создание веток, планирование сцен, генерация текста с речевыми профилями, диффы состояния, откат ранений и экспорт в Markdown/TXT.
3. **Arcs & Editorial:** управление арками, аудит старения сюжетных обещаний, редакторская оценка темпа и клише.
4. **Task Queue:** мониторинг фоновых процессов, статусы прогресса и лимиты расходов.

## 5. Запуск тестового набора (Automated Tests)

```bash
# Запуск всех 90 автоматических тестов
python -m pytest backend/tests -v
```
Все 90 тестов изолированы, используют временную SQLite БД, не требуют подключения к внешним сетям или платным ключам и гарантируют соблюдение архитектурных инвариантов.
